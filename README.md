# bank-account-python
A simple Python program that uses classes to manage a bank account, including account information, deposits, and withdrawals.

Features:
Create a bank account
Store account information
Display account information
Deposit money
Withdraw money
Check whether the account has enough balance


Technologies Used:
Python
Object-Oriented Programming (OOP)
Classes and Objects

How It Works:
The program defines a Bankacount class that contains information about a bank account, including:

Name
Account number
Balance
The class also contains methods for displaying account information, adding money, and withdrawing money.
The program creates an account object and gives it a name, account number, and initial balance.
The user can then add money to the account or withdraw money.
If the withdrawal amount is greater than the available balance, the program displays an insufficient balance message.

How to Run:
Run the following command in the terminal:
python bank_account.py
